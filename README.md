# 🏪 편의점

## 🎯 프로젝트 소개
편의점에서 상품을 구매하고 프로모션 할인과 멤버십 할인을 적용하여
최종 결제 금액을 계산하는 프로그램입니다.

## ✨ 주요 기능
1. 상품 목록 출력
2. 상품 구매 및 재고 관리
3. 프로모션 할인 적용
4. 멤버십 할인 적용
5. 영수증 출력

## 🏗️ 프로그램 실행 흐름
1. 상품 및 프로모션 정보 로드
2. 상품 목록 출력
3. 구매할 상품 입력
4. 프로모션 적용 여부 확인
5. 멤버십 할인 적용 여부 확인
6. 영수증 출력 및 재고 차감
7. 추가 구매 여부 확인

## 📦 기능 목록

### 1. 파일 입출력
- [x] `products.md` 파일을 읽어온다
- [x] `promotions.md` 파일을 읽어온다
- [x] 파일이 없거나 읽을 수 없으면 예외를 발생시킨다

### 2. 프로모션 기능
- [x] 프로모션 정보를 생성한다 (이름, 구매수량, 증정수량, 기간)
- [x] 프로모션 기간이 유효한지 확인한다
- [x] 구매 수량으로 증정 수량을 계산한다
- [x] 프로모션 적용 가능 개수를 계산한다

### 3. 상품 기능
- [x] 상품 정보를 생성한다 (이름, 가격, 수량, 프로모션)
- [x] 상품의 재고를 확인한다
- [x] 상품의 재고를 차감한다
- [x] 재고가 부족하면 예외를 발생시킨다
- [x] 상품 가격을 계산한다
- [x] 프로모션 상품인지 확인한다

### 4. 상품 저장소 기능
- [x] 여러 상품을 관리한다
- [x] 상품 이름으로 상품을 찾는다
- [x] 같은 상품의 프로모션/일반 재고를 함께 관리한다
- [x] 존재하지 않는 상품을 찾으면 예외를 발생시킨다

### 5. 구매 기능
- [x] 구매 입력을 파싱한다 (`[콜라-3],[사이다-2]`)
- [x] 입력 형식이 잘못되면 예외를 발생시킨다
- [x] 구매 가능 여부를 확인한다 (재고 체크)
- [x] 프로모션 추가 가능 여부를 확인한다
- [x] 사용자가 N개를 샀는데 N+1 프로모션인 경우 1개 추가 제안
- [x] 프로모션 재고 부족 여부를 확인한다
- [x] 일부 수량이 정가로 결제되어야 하는 경우 확인 요청

### 6. 할인 계산 기능
- [x] 프로모션 할인 금액을 계산한다
- [x] 멤버십 할인 금액을 계산한다 (프로모션 미적용 금액의 30%, 최대 8,000원)
- [x] 최종 결제 금액을 계산한다

### 7. 영수증 기능
- [x] 구매 상품 내역을 생성한다
- [x] 증정 상품 내역을 생성한다
- [x] 금액 정보를 생성한다 (총구매액, 행사할인, 멤버십할인, 내실도)
- [x] 영수증을 문자열로 포맷팅한다

### 8. 입력 기능
- [x] 구매할 상품과 수량을 입력받는다
- [x] 프로모션 추가 여부를 입력받는다 (Y/N)
- [x] 정가 구매 여부를 입력받는다 (Y/N)
- [x] 멤버십 할인 여부를 입력받는다 (Y/N)
- [x] 추가 구매 여부를 입력받는다 (Y/N)
- [x] 잘못된 입력이면 예외를 발생시킨다

### 9. 출력 기능
- [x] 환영 메시지를 출력한다
- [x] 상품 목록을 출력한다
- [x] 프로모션 재고가 있으면 프로모션 정보와 함께 출력
- [x] 일반 재고도 출력
- [x] 재고가 0이면 "재고 없음" 출력
- [x] 프로모션 추가 안내 메시지를 출력한다
- [x] 정가 구매 안내 메시지를 출력한다
- [x] 영수증을 출력한다
- [x] 에러 메시지를 출력한다

### 10. 전체 흐름 제어
- [x] 프로그램을 초기화한다 (파일 읽기, 상품/프로모션 생성)
- [x] 상품 목록을 출력한다
- [x] 구매 프로세스를 진행한다
- [x] 입력 받기
- [x] 검증하기
- [x] 확인 질문하기 (프로모션 추가, 정가 구매)
- [x] 할인 계산하기
- [x] 영수증 출력하기
- [x] 재고 차감하기
- [x] 추가 구매 여부를 확인한다
- [x] 예외 발생 시 에러 메시지를 출력하고 재입력 받는다
